### 📄 Publication

**ChainSWE: Benchmarking Coding Agents on Multi-Bug Software Maintenance**  
Qirui Jin, Lingching Tung, Kenan Li, Qiyang Shi, Yushi She, **Huanzhong Jia**, Harrison Zhao, et al.  
*EMNLP 2026 (Main Conference)*  
[Paper](https://aclanthology.org/2026.emnlp-main.371/) · [arXiv](https://arxiv.org/abs/2607.02606) · [Dataset 🤗](https://huggingface.co/datasets/C-lister/ChainSWE)

> The first benchmark for evaluating agents on sequential, dependent bug fixes within a shared codebase: chronological chains of 304 issues across 54 Python projects, mined from six SWE-bench-family datasets. Agent performance drops by up to 70% as the chain grows.
